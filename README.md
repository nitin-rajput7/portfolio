# Nitin Rajput Portfolio

A responsive, frontend-only React + Vite portfolio. Content is centralized in `src/data/portfolioData.js`.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Personal updates

- Update the phone number and portfolio content in `src/data/portfolioData.js`.
- Replace `public/resume/Nitin-Rajput-Resume.pdf` with Nitin's finalized resume when ready.
- Project buttons are intentionally omitted until real project URLs are available.

The contact form validates input then opens the visitor's email app; it does not claim to send or store messages.
